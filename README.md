This repository contains the projects I worked on during my C programming internship with CodeAlpha. I built these projects to improve my programming skills and understand how real applications are developed using C language.

Project 1: Calculator

This is a simple calculator program made in C.
It allows users to perform basic operations like:
- Addition
- Subtraction
- Multiplication
- Division
I used switch-case and loops to make a menu system so the user can use it again and again without restarting the program.

Project 2: Student Management System

This project is a simple system to manage student records.

With this program, we can:
- Add student details
- View all students
- Search a student by ID
- Delete a student record

I used file handling in C so that the data is saved even after closing the program.
